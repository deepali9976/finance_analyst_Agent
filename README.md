This project demonstrates a lightweight multi-agent system built with the Phidata framework. It consists of two core agents:

1. WebSearch Agent: Performs real-time web searches using Groq-hosted LLMs.
2. Finance Agent: Handles basic financial queries and tasks.

The system is entirely locally hosted using the Phidata playground, making it easy to test, customize, and expand. Ideal for exploring how modular agents can collaborate within a single AI workflow.
